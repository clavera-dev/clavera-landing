Визуального до/после сравнения ещё не делали — не было браузера в той сессии.

**Следующий безопасный локальный шаг.** `M5.2 — Hero`, по §13 `M4_REFERENCE_COMPOSITION_SPEC.md`: один сеанс с реальным браузером, где стоит сразу закрыть несколько накопившихся пунктов за одно открытие браузера —
1. прототипировать варианты H-1 A/Б для короткого телефона на 375×667 во всех трёх локалях;
